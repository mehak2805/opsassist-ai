# Password Reset

## Issue

Users may be unable to access their account because they have forgotten their password, their password has expired, or they are unable to complete the password reset process.

## Troubleshooting Steps

1. Verify the user's identity according to the organization's IT verification procedure.
2. Confirm the user's employee or account identifier.
3. Determine whether the account is locked, the password has expired, or the user has forgotten the password.
4. If self-service password reset is available, guide the user through the approved password reset process.
5. If the account is locked, follow the approved account-unlock procedure.
6. Ask the user to sign in again using the newly created password.
7. If the password reset is unsuccessful, create or escalate an IT support ticket.

## Resolution

A password reset is considered successful when the user can authenticate successfully with the new password.

## Escalation

Escalate the issue when:

- The user's identity cannot be verified.
- The account requires administrative intervention.
- The password reset process produces an unexpected error.
- The user remains unable to authenticate after the reset.
