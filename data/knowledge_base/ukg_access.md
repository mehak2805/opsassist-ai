# UKG Application Access

## Issue

Users may be unable to access the UKG application after installing the app on a new mobile device.

A common symptom is that the UKG application asks for a company URL, access code, or workspace access code.

## Troubleshooting Steps

1. Confirm that the user has installed the official UKG application.
2. Confirm that the user is using the correct company-provided access URL or access code.
3. Enter the provided URL or access code in the appropriate field in the UKG application.
4. Verify that the mobile device has an active internet connection.
5. Ask the user to close and reopen the UKG application after entering the access information.
6. If access is still unsuccessful, verify whether the user's account has the required application permissions.
7. If the issue cannot be resolved through these steps, create or escalate an IT support ticket.

## Resolution

If the correct access URL or access code is provided and accepted by the application, the user should be able to proceed with UKG login.

## Escalation

Escalate the issue when:

- The access code is rejected.
- The user does not have the required application permissions.
- The application continues to fail after troubleshooting.
- The user's account requires an administrative change.
